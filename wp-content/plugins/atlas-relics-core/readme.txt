Companion plugin for the Atlas Relics theme. Provides security hardening now, and grows into
fulfillment automation, customer workflows, and the admin operations dashboard in later phases.

== Description ==

Atlas Relics Core is developed alongside the Atlas Relics theme in three phases:

1. **Foundation** (current): security hardening and a scaffold for future content types.
2. **Storefront**: WooCommerce support, Beacons product import, bundle logic.
3. **Migration & automation**: fulfillment automation, MailerLite/Tally integration, the
   administrative operations dashboard, and migration reconciliation tooling.
